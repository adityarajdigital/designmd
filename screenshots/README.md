# Screenshots

This directory hosts UI screenshots of the live DesignMD site at [designmd.adityaraj.info](https://designmd.adityaraj.info).

## Recommended captures

To populate this directory, take screenshots of:

| File | What to capture | Recommended size |
|---|---|---|
| `homepage.png` | Homepage hero — "Pour any website's design DNA into a spec" | 1440×900 |
| `result.png` | A completed analysis showing the side panel + markdown body | 1440×900 |
| `benchmarks.png` | `/benchmarks` grid showing all category cards | 1440×900 |
| `category-ai.png` | `/benchmarks/category/ai` showing the AI category collection | 1440×900 |
| `benchmark-stripe.png` | A single benchmark page (Stripe is a strong example) | 1440×900 |
| `palette-panel.png` | Close-up of the extracted palette + typography card | 800×600 |
| `mobile-fold.png` | Mobile view of a benchmark page, showing the sidebar-first layout | 390×844 |

## Capture guidelines

- **Use the dark theme** (the production default — no theme-toggle interaction needed).
- **Hide your browser chrome** if possible — Cmd+Shift+F in Safari, full-screen in Chrome, etc.
- **PNG, not JPG** — keep typography sharp; size doesn't matter for static assets.
- **Don't include personally identifiable browser tabs** in the screenshot frame.

## Why this dir is empty in the initial commit

This is a public showcase repository. The screenshots are best captured by the project owner at the moment of publication so they reflect the most recent UI. Drop the PNGs in here, commit, and reference them from the main README as needed.
